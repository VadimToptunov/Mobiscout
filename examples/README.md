# Examples

Real artifacts produced by the tool, so you can see the output without running
anything.

## `shop_demo/` — a full crawl-kit

Generated by [`generate.py`](generate.py) from a small shopping app
(Login → Catalog → Product → Cart). It writes the kit through the **same code path
as `mobiscout crawl --style pom`** over a device-free crawl fixture, so it always
matches the current code. Refresh with:

```bash
python examples/generate.py
```

What's inside — every target is its own runnable project:

| Path | What it is |
|---|---|
| [`inventory.md`](shop_demo/inventory.md) / [`.json`](shop_demo/inventory.json) | Per-screen element inventory: semantic type + ranked locator per element, the flow map, the interaction-graph summary, and an accessibility section |
| [`graph.mmd`](shop_demo/graph.mmd) / [`.dot`](shop_demo/graph.dot) / [`.json`](shop_demo/graph.json) | Interaction graph — Mermaid (renders on GitHub), Graphviz and JSON (nodes, edges, metrics, dead-ends, hubs) |
| [`coverage.md`](shop_demo/coverage.md), [`defects.md`](shop_demo/defects.md), [`generation-report.md`](shop_demo/generation-report.md) | What the crawl reached vs what the kit tests, defects the crawl ran into, and anything that could not be generated |
| **[`python_pytest/`](shop_demo/python_pytest)** | **Python + pytest**: `pages/` (Page Objects), `conftest.py` (Appium fixture), `tests/test_<screen>.py`, `requirements.txt` |
| **[`python_pytest_bdd/`](shop_demo/python_pytest_bdd)**, **[`python_behave/`](shop_demo/python_behave)** | **BDD in Python**: `features/*.feature` + step modules over the same page objects |
| [`java_testng/`](shop_demo/java_testng) | Java + TestNG Maven project (`pom.xml`, page objects, base test, tests) |
| [`kotlin_appium/`](shop_demo/kotlin_appium) | Kotlin + JUnit Gradle project |
| [`js_webdriverio/`](shop_demo/js_webdriverio), [`js_cucumber/`](shop_demo/js_cucumber) | JavaScript npm projects — WebdriverIO specs, and Cucumber features + steps |
| [`flat/python_pytest/`](shop_demo/flat/python_pytest) | The same crawl as one standalone file (`--style flat`), for comparison |
| [`api/`](shop_demo/api) | API contract tests generated from an OpenAPI-style spec |

The point: **one crawl → an inventory, a navigation map, and a runnable suite** —
as a Page-Object framework or BDD, in several languages.
